# ПН-16-00 — IT-Skills + Unity, 2026–2027

Навчальний проєкт понеділкової групи. Початковий стан після заняття 07.09.2026: перехід до Unity, прості 3D-форми, положення, поворот, масштаб та матеріали.

## Відкриття проєкту

1. Завантажити або клонувати цей репозиторій.
2. Додати папку проєкту в Unity Hub.
3. Відкрити у Unity **6000.3.15f1** та дочекатися імпорту пакетів.
4. Відкрити сцену `Assets/Scenes/SampleScene.unity`.

У репозиторії зберігаються `Assets`, `Packages` і `ProjectSettings`. Локальні кеші `Library`, `Logs`, `UserSettings`, `ProfilerCaptures` та файли середовища розробки виключені через `.gitignore`.
